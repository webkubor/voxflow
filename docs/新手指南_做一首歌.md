# 做一首歌 · 从零开始

> 给第一次做 AI 音乐的人。**不需要装任何软件，Windows / Mac 都一样**，
> 全程在浏览器里完成。跟着做，20 分钟出一首歌。

---

## 你需要准备的只有两样东西

打开 Suno 之后，你只需要往两个框里粘贴文字：

| 要填的 | 是什么 | 例子 |
|---|---|---|
| **风格标签** | 告诉 AI 用什么乐器、什么感觉、多快 | `ukulele, whistling, quirky, 100 BPM` |
| **歌词** | 要唱的内容。不要人声就留空 | `[Verse]\n早上九点打卡机…` |

**这份文档的全部目的，就是帮你把这两段文字准备好。** 准备好了，剩下的就是粘贴和点按钮。

---

## 第一步：先决定要不要人声

这是最容易搞错的一步，**选错了做出来的东西完全不是你要的**。

| 你想要的 | 选哪个 | 歌词框 |
|---|---|---|
| 有人唱歌 | **Song（歌曲）** | 写歌词 |
| 只有背景音乐，没人唱 | **Instrumental（纯音乐 / BGM）** | **留空**，并把开关打开 |

> 在 Suno 网页上，纯音乐是一个叫 **Instrumental** 的开关。
> 在 VoxFlow 里，是「AI 音乐」页面上方的 **BGM · 纯背景音** 那个卡片。
>
> 常见错误：想要纯音乐，但歌词框里留了字 → 出来的还是有人唱的。**歌词框必须空**。

---

## 第二步：写风格标签（最关键的一步）

### 一条铁律：写**乐器名**，不要写心情

AI 认得出 `bassoon`（低音管），认不出「搞笑」。

| ❌ 这样写没用 | ✅ 这样写才有效 |
|---|---|
| funny, 搞笑, 好玩 | `ukulele, whistling, slide whistle` |
| 悲伤, 感人 | `sad piano, cello, slow strings` |
| 高级感 | `lo-fi, vinyl crackle, jazz chords` |

### 直接抄这些（实测出得来的）

**搞笑 / 翻车尴尬**（短视频最常用）
```
ukulele, whistling, hand claps, quirky, awkward comedy, lighthearted, 100 BPM
```

**卡通滑稽 / 蹑手蹑脚**（像动画片配乐）
```
cartoon orchestra, pizzicato strings, bassoon, xylophone, slide whistle, mischievous, 130 BPM
```

**年轻女声 · 洗脑流行**（要有人唱时用）
```
electropop, hyperpop, bright young female vocal, gen-z, catchy hook, viral, 128 BPM
```

**深夜伤感**
```
sad piano, emotional strings, lo-fi, melancholic, 80 BPM
```

**国潮古风**
```
chinese folk, guzheng, erhu, cinematic, traditional, 100 BPM
```

**励志燃**
```
epic orchestral, cinematic, inspirational, building, 120 BPM
```

### 最后那个数字是什么

`120 BPM` = 每分钟 120 拍，**决定歌快还是慢**：

- `60-80` 慢，适合抒情、助眠
- `100-120` 中速，适合大部分场景
- `128-140` 快，适合卡点、运动、搞笑

### 想要纯音乐，再加一道保险

在风格标签最后加上 `instrumental`，并在「排除风格」（Exclude Styles）里填：
```
vocals, singing, voice, lyrics
```
这样 AI 就不会偷偷加人声进来。

## 第三步：写歌词（只有要人声时才需要）

### 格式：用方括号标出段落

Suno 靠这些标记知道哪里是主歌、哪里是副歌：

```
[Verse]
早上九点打卡机 灵魂还锁在被窝里
咖啡续到第三杯 眼睛睁着脑子在飞

[Chorus]
摸鱼 摸鱼 我是一条快乐的鱼
工位就是我的海底 谁也别想抓到我

[Verse 2]
群里消息九十九 我已读不回装成熟
会议开了两小时 结论是下次再讨论
```

常用标记：`[Verse]` 主歌 · `[Chorus]` 副歌 · `[Bridge]` 过渡 · `[Outro]` 结尾

### 写词的三个经验

1. **副歌要短、要重复**。人记住的永远是副歌，「摸鱼 摸鱼」这种重复比华丽的句子有用。
2. **一句话别太长**。唱不下就会被 AI 切得很怪。一句 10-15 个字比较稳。
3. **懒得写就留空**。歌词框空着、但不开 Instrumental 开关，Suno 会自己按风格编词——出来的词通常一般，但能听。

---

## 第四步：生成

1. 打开 https://suno.com/create
2. 打开 **Custom（自定义）** 模式——不然它只认一句话描述，控制不了细节
3. 三个框分别填：**标题** / **风格标签** / **歌词**
4. 纯音乐的话把 **Instrumental** 开关打开
5. 点 **Create**

**一次会出两首**，同样的设置、两种不同演绎。等 1-3 分钟。

---

## 第五步：挑一首，下载

两首都听完再决定——它们经常差别很大。

选好之后，在歌曲上点 **⋯ → Download → MP3/WAV**。

> **用 VoxFlow 的话这一步可以省**：在「AI 音乐」页生成的歌会自动下载到本地，
> 存在 `音频文件` 那一栏里，不用手动点。

---

## 出来的东西不对？照这个表查

| 问题 | 原因 | 怎么改 |
|---|---|---|
| 想要纯音乐，结果有人唱 | 歌词框没清空，或没开 Instrumental | 清空歌词 + 打开开关 + 排除 `vocals, singing` |
| 完全不像我要的风格 | 标签写了心情词 | 换成乐器名，见第二步 |
| 太快 / 太慢 | BPM 不对 | 改最后那个数字 |
| 唱得很怪、咬字不清 | 单句太长 | 把长句拆成两句 |
| 两首都不满意 | 正常，AI 有随机性 | 同样的设置再点一次，会出新的两首 |
| 中文歌唱出外国腔 | 标签里没说中文 | 加 `mandarin` 或 `chinese pop` |

Suno 按 **credits** 计费，**一次生成（出两首）扣一份**。
Pro 套餐每月 2500 credits。具体单价以你账号页面显示的为准。

**注意：失败也可能扣费。** 所以不要连点生成按钮，等它出结果再说。
