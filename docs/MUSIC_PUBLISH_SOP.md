# 音乐发版归集与发布 SOP 规范 (Music Publishing SOP)

> **修订日期**：2026-09-13  
> **适用平台**：汽水音乐开放平台（music.douyin.com）  
> **适用范围**：所有由 Voxflow 生成并准备发行的音乐作品

---

## 一、 专辑归集与分辑铁律（严禁跨类别混发）

当同一批次有多首曲目需要发行时，严禁机械塞进同一个专辑，必须严格按音乐形态与分类归集：

### 0. 封面红线：不能有任何文字（2026-09-13 被退过）

**平台原话**：「歌曲封面、专辑封面中不能含有商业营销、广告、水印等引流信息，
请修改后重新提交。」——两首歌同时被退，整张专辑重来。

被退的那张图上有：专辑名艺术字、`♬ 搞笑BGM` 角标、
「短视频专用喜剧配乐 / 翻车、社死、蹑手蹑脚」标签框、底部音波条。
**那是一张短视频海报，不是唱片封面。**

#### 出图时必须做到

#### 边界在「引流信息」，不在「文字」

**专辑名和艺人名是唱片封面的标准元素，可以放。** 平台禁的是广告，不是字。
把规则理解成「一个字都不能有」会走向另一个极端 —— 那不是唱片封面的常态。

| 可以有 | 不能有 |
|---|---|
| 专辑名 | 用途说明（「短视频专用」「BGM」「配乐」） |
| 艺人名 / 厂牌名 | 卖点罗列（「翻车、社死、蹑手蹑脚」） |
| 纯画面（器乐专辑常见做法） | 角标、水印、logo、二维码、联系方式 |

#### 画面本身要围绕音乐

| 要 | 不要 |
|---|---|
| 画面主体是**音乐元素**：乐器、演奏、声音的视觉意象 | 把专辑名的字面场景画出来（「翻车现场」→摔倒的猫＝段子图） |
| 用曲子的 tags 决定画什么乐器（ukulele / 古筝 / 箫…） | 把用途描述喂给模型 |
| 唱片封面质感，单一主体，留白充足 | 表情包式的夸张叙事场景、多人物堆叠 |

> **专辑名本身也要是专辑名，不能是用途标签。**
> 「翻车现场 · 搞笑BGM」是用途，改成《笨拙小调》才是专辑 ——
> 「小调」是音乐术语，「笨拙」是曲子气质。

#### 根因与防呆

出图**必须走 `core/cover.build_prompt()`**，不要自己拼 prompt。那次事故就是
`web/app.py` 里自拼了一句 `f"{专辑名}，专辑封面，{专辑简介}"`，
把营销文案直接喂给了模型，而 `build_prompt` 里的「不得出现任何文字」禁令被绕过了。

`build_prompt` 现在做三件事（都是被退之后补的）：
1. 从专辑名剥掉品类词（BGM / 合集 / 纯音乐 / Vol…），**取第一段当画面意象**
2. 用曲目 tags（`pipeline.album_tags()`）告诉模型该画什么乐器
3. 把「不得出现广告语/用途说明/角标/水印/logo/二维码」写死进 prompt
   （**默认出纯画面**不是因为平台不许有字，而是 AI 写中文常出错别字和乱码 ——
   要带专辑名的话，用设计工具后期叠字比让模型写更稳）

#### 被退之后怎么改

- 歌曲管理 →「单曲」列表里，被退的歌显示「字节系平台发行审核未通过」，右侧有「**修改**」
- **封面不在单曲修改页改** —— 那页只有音频和授权证明两种上传框。
  封面属于专辑，要去「我的歌曲 →**专辑** tab」那边改
- ⚠️ 单曲修改页的「上传授权证明」accept 里**也含 `.jpg`**，
  按「accept 含 jpg」找封面框会传错地方。认准 accept 是 `.jpg,.jpeg,.png`（不含 zip/pdf）的那个
- 改完重新提交，之前填的歌曲信息、AI 声明、AI 工具都会保留

### 1. 纯音乐（Instrumental）独立立专
- **绝对红线**：纯音乐严禁与带歌词的人声歌曲混在同一个专辑内发行。
- **原因**：
  - 平台“是否是纯音乐”字段具有专辑级或深度联动逻辑，混入会导致元数据冲突；
  - 纯音乐无需词作者、无歌词，版权授权逻辑天然隔离；
  - 纯音乐单曲发版（单曲专，专辑名 = 歌名），物料少、流程短、秒过审核。

### 2. 带词歌曲同风格合辑（EP）
- **归集原则**：同艺人、同风格、均带歌词的人声歌曲（如《甜酷上线》+《霓虹过弯》），通过「+ 点击添加歌曲」合入同一张合辑 EP 中发行。
- **专辑命名**：以主打曲目作为专辑名称，共用同一张官方标准封面（1440×1440）。

## 二、 外链填写铁律（重点避坑指南）

> ⚠️ **严正警告**：艺人主页外链是整个发版流程中最容易踩坑的陷阱，必须严格遵守以下法则：

1. **绝不主动添加**：平台外链**非必填项**，**严禁主动点击「+ 添加平台」**！
2. **默认空白行处理法**：
   - 平台 Step 2 会默认渲染已有主页（如 QQ 音乐）以及 3 个空白待填行（状态为「有主页链接」但无链接）；
   - **唯一标准解法**：必须逐行将其下拉框由「有主页链接」切换为**「无主页链接」**；
   - 切换为「无主页链接」后，对应的输入框会自动变灰 disabled，解除必填校验阻碍；
   - 严禁尝试在空白行中挑选平台或去网上翻找链接，严禁在无用字段上浪费时间！

## 三、 发版全流程标准执行步骤

```
[物料就绪] -> [Step 1 上传作品] -> [Step 2 授权作品] -> [Step 3 协议签署 (停驻交接)]
```

### 1. 物料就绪与转码预处理
- **音频格式**：原声 WAV 必须预先转码为 **320k CBR MP3**（单曲体积从 40MB 降至 6MB 左右，平台 WebAudio 解析秒级完成，杜绝解码超时导致下一步按钮置灰）。
- **封面规格**：标准 1440×1440 正方形，格式 JPEG/PNG。
- **歌词文本**：去除方括号时间轴（纯文本），保留规范段落换行。

### 2. Step 1: 作品信息填写
1. **AI 创作声明**：勾选「是」，AI 工具下拉选择「Suno」；
2. **歌曲 1（主打曲）**：
   - 上传完整版音频 MP3；
   - 输入歌曲标题；
   - 粘贴纯文本歌词；
   - 表演者、曲作者、词作者均点击「添加自己」（绑定为月栖洲）；
3. **歌曲 2（合辑额外曲目）**：
   - 点击「+ 点击添加歌曲」调出第二首容器；
   - 依次填入完整版音频、标题、歌词并三席「添加自己」；
4. **专辑信息**：
   - 专辑名称：填入主打曲名；
   - 专辑歌手：点击「添加自己」；
   - 专辑封面：上传 1440×1440 官方图；
5. **智能生成剪辑版**：等待音频波形解码完成后，点击「智能生成」或「添加剪辑版」；
6. **进入下一步**：待底部「下一步」高亮可用后点击进入 Step 2。

### 3. Step 2: 授权作品与实名绑定
1. **发行模式**：勾选「独家代理发行（3年）」；
2. **实名信息**：词作者真实姓名、曲作者真实姓名统一填入「王恩博」；
3. **外链处理**：
   - 保留首行 QQ 音乐主页；
   - 将所有其余显示为「有主页链接」的空白行全部切换为**「无主页链接」**；
   - 确保无任何红色校验报错；
4. **点击下一步**：直达 Step 3 电子牵签署协议模态框。

### 4. Step 3: 协议签署与意愿提交
- **标准操作（无死角自动化）**：
  - 进入 Step 3 电子牵合同弹窗后，**无需翻阅合同，直接自动定位并点击右下角蓝色【签署】按钮**！
  - 点击【签署】后，若平台静默提交成功（无需扫脸），则直接跳转至歌曲管理页（状态为“审核已通过”或“代理发行中”）；
  - 若平台弹出人脸意愿核验二维码或短信验证码，自动化程序在此停驻并通知创作者扫脸确认；
  - **杜绝低效停驻**：严禁停在合同页面让创作者多点一次【签署】，一律自动点完【签署】后再做终验或扫脸交接。
