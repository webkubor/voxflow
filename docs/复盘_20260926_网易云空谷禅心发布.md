### 问题 2（技术）：歌词字段是 Quill 富文本编辑器

这个卡了 5 轮，是当时最显眼的障碍，但**不是**本次失败的主因。

- 网易云的「歌词」字段不是 textarea，是 **Quill 富文本编辑器**（`contenteditable` div）
- 空白态 `<p><br></p>` 被校验判为「歌词不能为空」
- 报错文案在页面上可见（`top=1447`），而**它正上方 20px 就是那个 Quill 编辑器** —— 线索一直在眼皮底下
- 正解：`focus` 编辑器 + `document.execCommand('insertText')` 触发一次**真实输入**，`lyricObj` 才变成合法对象 `{"lyric":""}`，`下一步` 才放行

填好后流程一路畅通：`songupload` → `incomeconfig`（收益设置）→ `authorization`（签约授权）→ 短信验证 → `publishsuccess`。

## 可复用的方法论（已沉淀）

### 1. 表单校验失败时：先定位字段，再看控件类型
> 错误文案的 DOM 位置 → 往上找最近的表单项 → 判断控件是 input / select / **富文本**。
> **不要猜规则，不要改 state 绕过。**

### 2. React / antd 受控组件必须用真实输入事件
> 改 `value` / `innerHTML` 无效；`focus` + `execCommand('insertText')` 或 CDP 键盘输入才生效。
> 被隐藏的浮层（tooltip / popover）**必须先让 React 真实打开**（点击触发）；用 CSS 强制 `display:block` 会让受控 input 拒绝写入。

### 3. 红字消失 ≠ 问题解决
> 表单里让某个必填提示不再显示，可能只是遮住了症状。要**核实实体是否真的建立/关联正确**。
> 本次的教训：专辑红字消失后，应该去「专辑管理」确认《空谷禅心》真的存在。
